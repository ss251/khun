# Build Prep — Khun (no-faking edition)

## AWS Credits + Kiro Onboarding (provided by Sailesh)

### Step 1 — Redeem the AWS Credit Code
1. Sign in to the AWS Management Console
2. Account name (top right) → **Billing and Cost Management**
3. Left sidebar → **Credits**
4. **Promotional Credit** section → enter code → **Redeem**
5. Verify the credit appears in the Credits list

### Step 2 — Ensure Payment Method is Added
Even with credits, AWS requires a payment method on file:
1. Billing → **Payment methods** (left sidebar)
2. Add a credit/debit card (will not be charged if credits cover cost)

### Step 3 — Subscribe to Kiro
1. AWS Marketplace (or wherever the Kiro listing is)
2. Create a Kiro subscription for 1 user
3. Credits apply automatically

### Step 4 (Khun-specific) — Request Bedrock Claude 4.7 access
1. AWS Console → **Bedrock** → Model access
2. Request access for **Anthropic Claude 4.7** (and Nova as backup) in the chosen region
3. Lead time 15–60 min — do this FIRST so it's approved by the time onboarding flow needs it
